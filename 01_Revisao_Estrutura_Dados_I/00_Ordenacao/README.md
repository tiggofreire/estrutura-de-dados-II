# Algoritmos de ordenação em C

Implementação didática de Bubble Sort, Selection Sort, Insertion Sort e Quick Sort, com menu para preencher, imprimir e ordenar um vetor.

O código-fonte está em [`Algoritmos_de_Ordenacao_C.c`](Algoritmos_de_Ordenacao_C.c).

**Observação:** a implementação original usa `<conio.h>` e `getch()`, recursos não disponíveis em todos os compiladores C. O código foi preservado sem adaptação de portabilidade.
