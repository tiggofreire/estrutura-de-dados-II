# Estrutura de Dados II — Material de Estudo e Atividades

Repositório organizado por unidades temáticas, reunindo revisões, materiais didáticos, exercícios e atividades práticas de **Estrutura de Dados II**.

O material foi consolidado a partir de exercícios e referências de estudo usados ao longo da disciplina. **A presença de um arquivo neste repositório não indica autoria individual**. Documentos e trabalhos em grupo mantêm seus créditos internos quando existentes.

## Como abrir os materiais

- **`.md`**: textos e enunciados em Markdown; visualizar no GitHub ou VS Code.
- **`.ipynb`**: notebooks para Jupyter Notebook, VS Code ou Google Colab.
- **`.py`**: scripts Python; executar com Python 3, preferencialmente a partir da pasta do repositório.
- **`.c` / `.cpp`**: código-fonte em C e C++; exigem compilador correspondente.
- **`.html`**: abrir no navegador (jogo Red-Black Bowling).
- **`.pdf`**: apresentações e material didático.

## Limites e organização

- As pastas de grafos contêm material didático e atividades de referência, inclusive o ConectaUDF, e **não são declaradas como o projeto final do autor deste repositório**.
- O **projeto final da disciplina ainda não foi incorporado**.
- Arquivos podem ter autores diferentes; o nome padronizado indica **tema/função**, não autoria.
- O conteúdo original foi preservado sempre que possível; ajustes específicos incluem correção de extensões, retirada de links desatualizados e remoção de um PDF individual de revisão por solicitação.
