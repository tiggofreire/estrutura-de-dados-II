# Revisão de Estrutura de Dados I

Este projeto foi desenvolvido com base nos conteúdos estudados em Estrutura de Dados I.

## Pilha

A implementação apresenta uma estrutura de dados do tipo **Pilha (Stack)**, que segue o princípio **LIFO** (*Last In, First Out*), onde o último elemento inserido é o primeiro a ser removido.

Foram implementadas as seguintes operações:

- `push()` — adiciona um elemento;
- `pop()` — remove o elemento do topo;
- `top()` — consulta o elemento do topo;
- `empty()` — verifica se a pilha está vazia;
- `mostrar()` — exibe os elementos da pilha.

## Tecnologias

- C++
- Estruturas de Dados
- Programação Orientada a Objetos

## Objetivo

Revisar os conceitos de pilhas, vetores, classes e operações básicas de estruturas de dados, servindo como preparação para os conteúdos de Estrutura de Dados II.
